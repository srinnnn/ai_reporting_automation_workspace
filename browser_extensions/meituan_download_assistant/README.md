# Meituan Report Download Assistant

这个目录是美团报表下载助手的浏览器插件草案。它的定位是“读页面 + 点官方导出 + 规范下载文件名”，不保存账号密码，不绕过验证码，不调用隐藏接口，不做任何后台配置操作。

## 两种模式

手动模式：

1. 业务先登录美团后台。
2. 在插件里选择品牌、日期、报表类型。
3. 点击“手动模式：记录下一次下载”。
4. 业务自己在美团后台点击官方导出或下载。
5. 插件把下载文件归档到 Chrome 默认下载目录下的 `meituan_auto_download/<brand>/<channel>/<date>/<file_type>/`。

自动模式：

1. 业务先登录美团后台并进入报表下载相关页面。
2. 在插件里选择品牌、日期、报表类型，并多选需要导出的数据指标。
3. 点击“自动模式：当前报表创建并下载”，或点击“自动模式：三张日报报表一键导出”。
4. 插件会按顺序尝试：进入报表页签、选择数据类型、填写日期、勾选指标、点击查询/搜索、点击导出/下载。
5. 插件只会点击白名单动作：查询、搜索、导出、下载、报表下载、生成报表。
6. 遇到保存、提交、发布、上架、下架、删除、配置等按钮时，插件不会点击。

自动模式仍然依赖美团页面当前可见结构。如果某个页面把指标选择或导出按钮放在弹窗/iframe/隐藏面板里，插件会返回“页签、类型、日期、查询、指标、导出”的执行明细，业务可据此先切到正确页面后再执行。

## 浏览器权限边界

Chrome 插件不能直接写入任意绝对路径，只能控制浏览器下载目录下的相对路径。所以插件负责下载归档，本地同步脚本负责把文件复制到内网工作台入库目录。

推荐链路：

```text
美团后台官方导出
  -> Chrome Downloads/meituan_auto_download
  -> tools/meituan_download_assistant_sync.py
  -> intranet_app/runtime/intake/meituan_auto_download
  -> 数据入库中心字段映射与校验
  -> 统一基础数据层
```

## 加载方式

1. 打开 Chrome 扩展程序页面：`chrome://extensions/`
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`browser_extensions/meituan_download_assistant`。

## 当前覆盖报表

- `product_order`：商品/订单数据
- `store_finance`：门店财务数据
- `store_traffic`：门店流量数据
- `service_review`：服务评价数据，仅用于手动导出、周报/月报或服务复盘；不作为日报必需数据。

日报一键导出只包含 `product_order`、`store_finance`、`store_traffic` 三张表。美团服务评价数据存在平台延迟，2026-07-28 后台最新只能取到 2026-07-26，因此日报默认不再输出评价服务板块。

后续如果美团页面按钮文案或路径变化，只改 `rules/meituan_reports.json` 和 `content_script.js` 中对应的报表规则，不改统一基础数据层。
