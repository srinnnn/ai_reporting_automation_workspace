# AI报表与配置开发资料包放置说明

当前按 03 的逻辑统一：每个一级业务文件夹都保留一个 `示例参考.md`，并配置 `需提供资料` 目录用于放该模块通用资料类型。

## 目录用途

- `00_资料索引表`：所有资料的登记入口。
- `00_提交文件夹`：业务文件统一投递入口，系统扫描后自动归档并登记索引。
- `01_数据处理`：短彩信数据处理、日报、周报、月报。
- `02_品牌内容资料`：品牌规范、商品卖点、历史文案、禁用词、活动日历。
- `03_配置自动化资料`：按品牌和配置场景归档。当前安踏放在 `03-1_安踏`。
- `04_页面巡检复盘`：页面链接、巡检标准、历史问题、活动复盘、竞品和对账资料。
- `05_权限与业务方`：品牌、平台、业务方、审批人、推送对象、权限范围。
- `99_旧结构_暂不使用`：历史目录，仅用于保留旧结构资料，不再新增资料。

## 放置规则

1. 所有资料先放入 `00_提交文件夹/01_待处理`。
2. 在内网工作台首页点击 `扫描并归档`，或双击项目根目录的 `自动归档提交文件夹.bat`。
3. 系统会自动复制文件到对应 P1-P4 资料目录，并把提交原件移动到 `00_提交文件夹/02_已处理`。
4. 系统无法判断的文件会移动到 `00_提交文件夹/03_无法判定`，请补充文件名后重新放回待处理文件夹。
5. 文件名建议使用：`品牌_平台_项目_资料类型_日期范围.xlsx`。
6. 自动登记结果会写入 `00_资料索引表/资料索引表.csv` 和 `00_资料索引表/数据字典.csv`。
7. 原始数据优先放 `.xlsx` 或 `.csv`，第一行必须是表头，不要合并单元格。
8. 涉及会员、手机号、订单明细等敏感信息时，请先脱敏。
9. 不要放账号密码；后台流程用截图、录屏、导入模板、字段说明替代。

## 自动判定关键词

- P1 数据处理：短彩信、短信、彩信、日报、周报、月报。
- P2 品牌内容资料：AI选品、选品、品牌规范、品牌调性、商品卖点、历史文案、禁用词、活动日历。
- P3 配置自动化：安踏即时零售、上下架、上架、下架、货盘、素材、黑名单、美团商品表、京东商品表。
- P4 页面巡检复盘：页面链接、巡检标准、历史问题、复盘、竞品、对账。
